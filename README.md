## ⌨️ My workflow

I started with Neovim from day one. No VS Code for me: I jumped straight into the fire, and now I can't imagine programming any other way.

```bash
$ nvim      # write the code
$ git       # keep it safe
$ claude    # think it through with Claude Code
$ repeat    # until it ships
```
